# Synthetic Test Fixtures

This directory will contain synthetic invoice documents and test payloads used to prove both happy-path and failure-path behavior.

Planned fixtures include:

- valid low-value invoice;
- valid invoice requiring approval;
- duplicate invoice pair;
- unknown vendor invoice;
- inconsistent-total invoice;
- low-confidence / incomplete extraction case;
- malformed webhook payload;
- mocked transient external-service failure.

All fixtures must be fictional and must not contain real personal, employer, vendor, banking, or confidential information.
